# 🏠 Помощник по выбору квартиры в Слупске (Otodom & OLX Tracker)

Проект создан для удобного поиска, анализа и совместного трекинга квартир в Слупске (Słupsk, Польша) с платформ **Otodom** и **OLX**.

---

## 🚀 Быстрый старт (Локально на Raspberry Pi)

Веб-интерфейс запущен в виде системного сервиса:
- 🌐 **Адрес в браузере:** [http://localhost:5050](http://localhost:5050)
- Если открываете со смартфона в домашней Wi-Fi сети: `http://<IP-вашего-ПК>:5050`

### Управление сервисом:
```bash
cd /home/yauhen/slupsk_apartments
./start.sh status   # Проверить статус
./start.sh restart  # Перезапустить
./start.sh stop     # Остановить
./start.sh logs     # Смотреть логи в реальном времени
```

## 👫 Как работает совместная живая синхронизация (Supabase Live Sync)

Все лайки, заметки, телефонные договоренности, статусы («Жду ответа», «Просмотр») и рейтинги синхронизируются между вашими телефонами через **Supabase** (намного проще Firebase!):

1. **Создание бесплатной базы в Supabase (1 минута):**
   - Перейдите на [supabase.com](https://supabase.com) и войдите через GitHub или Google.
   - Нажмите **New Project** (назовите, например, `slupsk`, придумайте пароль базы).
   - В меню слева откройте **SQL Editor** и выполните команду (кнопка **Run**):
     ```sql
     create table if not exists apartments (id bigint primary key, data jsonb not null);
     alter table apartments enable row level security;
     create policy "public_all" on apartments for all using (true) with check (true);
     alter publication supabase_realtime add table apartments;
     ```
   - В меню слева откройте **Project Settings → API** и скопируйте:
     - **Project URL**
     - **anon public key**
2. **В веб-интерфейсе:**
   - Нажмите иконку **⚙️** (или плашку статуса синхронизации вверху).
   - Вставьте URL и anon key, затем нажмите **«Сохранить и подключить»**.
   - Нажмите **«Скопировать ссылку для девушки»** и отправьте ей ссылку.
   - Когда она откроет ссылку на смартфоне, **её телефон подключится автоматически** — ей вообще ничего настраивать не нужно! Любой ваш лайк или комментарий появится у неё на экране в ту же секунду!
3. **Офлайн и резервные копии:**
   - При отсутствии интернета все правки надежно сохраняются в памяти телефона (`localStorage`).
   - В меню ⚙️ доступны кнопки **Скачать JSON** и **Загрузить JSON** для полного бэкапа данных.

## 🛠 Ключевые возможности:

1. **Мгновенная скорость работы (60 FPS):**
   - Полностью устранены зависания: тяжелый браузерный runtime-компилятор Tailwind Play (407 КБ) заменен на оптимизированный CSS.
   - Внедрен debounced-поиск, убрана нагрузка на event loop.
2. **Удобный мобильный интерфейс:**
   - Адаптивная лента для смартфонов.
   - Крупные touch-кнопки (сердечки, статусы, звезды рейтинга).
   - Звонок владельцу в 1 клик (`tel:...`).
   - Горизонтальная панель фильтров со свайпом.
3. **Фокус на главном при выборе жилья:**
   - Убран лишний визуальный шум и громоздкая средняя цена.
   - Крупная итоговая стоимость месяца + прозрачный czynsz.
   - Яркое выделение типа отопления (городское, газовое, электрическое).
   - Четкие блоки подводных камней и рисков.
